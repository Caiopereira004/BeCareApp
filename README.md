# GlowUp — Aplicativo Completo (v8)

## Como testar rapidamente no celular ou computador
1. **Prévia Web Móvel (`web_preview/index.html`):** Abra diretamente no navegador do celular ou PC, ou hospede gratuitamente arrastando a pasta `web_preview` para o **Netlify Drop** (`app.netlify.com/drop`) ou **Vercel** para acessar por link HTTPS no seu celular.
2. **Código Flutter (`flutter_app/`):** Execute `flutter pub get` e `flutter run` para rodar nativamente no Android/iOS ou editar online no **idx.google.com** / **FlutLab**.
3. **Backend & Banco de Dados (`backend/` e `database/`):** Configure o `.env` com sua URI do MongoDB Atlas (`BeCareWeb`) e execute `npm install && npm start`.
